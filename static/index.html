System architecture: three-tier pipeline

1. Data processing layer

  • Ingestion: Raw NITI Aayog SDG India Index CSV spreadsheets (2018–2023).
  • Cleansing: Standardizes 36 state/column names and removes null values.
  • Transformation: Year string to integer format, long-format reshaping.

2. Machine learning & forecasting layer

  • Modeling: 108 independent Scikit-learn Random Forest Regressor models.
  • Projections: State-level composite index scores for 2024, 2025, and 2026 with tree-variance 95% CIs.
  • Risk classifier: Low Risk (≥75) · Medium Risk (50–74) · High Risk (<50).

3. Visualisation layer

  • Framework: High-performance custom web application for policymakers.
  • Features: Dynamic dropdowns, 95% CI shaded bands, spatial analytics.
  • Export: Automated 1-click downloadable CSV reports.
